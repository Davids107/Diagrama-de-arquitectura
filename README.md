# Diagrama de arquitectura
Figura 1 del Proyecto 2 de Arquitectura de Computadoras, Universidad Da Vinci de Guatemala.
Muestra la arquitectura propuesta en Azure (región México Central) para Agroinsumos Cuchumatán, S. A.: tres sedes conectadas por VPN, ERP en dos zonas de disponibilidad, archivos, respaldo y servicios administrados.
