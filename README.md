# Diagrama de arquitectura

Se agrega la documentación correspondiente a la Figura 1 del Proyecto Infraestructura Cloud y HCI - Arquitectura de Computadoras, que presenta la arquitectura propuesta en Microsoft Azure para Agroinsumos Cuchumatán, S. A.

El diagrama representa la conexión de tres sedes mediante VPN, la implementación del ERP en dos zonas de disponibilidad y los servicios de almacenamiento, respaldo y administración en la región México Central.

Se incluyen los siguientes archivos:
- `Figura1_Arquitectura_Azure.png`
- `Figura1_Arquitectura_Azure.drawio` (archivo editable en diagrams.net).
